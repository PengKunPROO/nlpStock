# 策略选股器 · UX 设计方案

> 基于 ui-ux-pro-max 设计规范（119 条 UX 准则 + pro-rules 交付清单）+ 项目现状分析，产出的可落地 UX 方案。
> 目标：简约精致、浅色为主、过渡丝滑、响应式自适应、控件不挤压。

---

## 一、项目定位与用户画像

| 维度 | 现状 |
|---|---|
| 产品类型 | 金融工具（A股选股 / 回测 / 行情图表） |
| 目标用户 | 散户投资者（非专业量化，用自然语言描述策略） |
| 使用场景 | 盘后选股回测 + 盘中看盘（K线、自选股） |
| 设备 | 手机（APK，Chaquopy 自闭环）+ 网页（PC 浏览器） |
| 核心流程 | 自然语言建策略 → 选股 → 勾选回测 → 看报告/K线回放 |

**核心洞察**：用户是「非技术散户」，界面必须把「量化字段」翻译成「人话」（如 `pnl_pct`→「浮盈亏%」、`lag`→「前移N日」），这是本项目 UX 的第一原则。

---

## 二、设计原则（5 条）

1. **简约精致（Minimalism & Swiss）**：克制 > 堆砌，用留白和对比建立层次，不用边框堆叠。
2. **浅色为主 + 深色模式**：浅色是默认，深色通过 `prefers-color-scheme` 自动切换（现有已实现）。
3. **数据优先**：K线、指标、收益率是核心，装饰让位于数据可读性。
4. **移动优先 + 响应式**：手机全屏，桌面端放宽到 900px，不写死 520px。
5. **触控友好 + 无障碍**：触控目标 ≥44px，对比度 ≥4.5:1，支持 reduced-motion。

## 三、设计系统（Design System）

### 3.1 配色（语义 token，浅色为主）

保留现有 Apple HIG 浅色调，仅微调对比度：

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F2F2F7` | 页面背景 |
| `--card` | `#FFFFFF` | 卡片/浮层 |
| `--card-2` | `#F7F7FA` | 次级卡片/输入框底 |
| `--text` | `#1C1C1E` | 主文本（对比度 15.6:1 ✅） |
| `--text-2` | `#3C3C43` | 次级文本 |
| `--text-3` | `#8E8E93` | 辅助文本（仅用于标签，不作正文） |
| `--accent` | `#007AFF` | 主操作/强调（iOS 蓝） |
| `--up` / `--down` | `#FA5151` / `#07C160` | **A股口径：红涨绿跌** |
| `--danger` | `#FF3B30` | 危险/删除 |

**关键规则**：涨跌颜色沿用 A股惯例（红涨绿跌），与国内用户心智一致，不用国际绿涨红跌。

### 3.2 字体

- 中文：`PingFang SC / Noto Sans SC`（系统默认，清晰）
- 数字：`font-variant-numeric: tabular-nums`（等宽数字，K线价格/收益对齐不跳动）——现有 `--mono` 已实现
- 字号层级：正文 16px / 标题 17-26px / 辅助 12-13px（辅助不得 <12px）

### 3.3 间距（8pt 系统）

| 层级 | 值 |
|---|---|
| 页面留白 | 16px |
| 卡片内边距 | 16px |
| 卡片间距 | 14px |
| 控件间距 | 8-10px |
| section 标题间距 | 20px 上 / 8px 下 |

### 3.4 圆角 / 阴影 / 层级

- 圆角：卡片 16px / 输入框 10px / 按钮 12px / chip 100px
- 阴影：`0 1px 3px rgba(0,0,0,0.06)`（轻，不浮夸）
- z-index 层级：view 内容 0 → nav-header 20 → tabbar 30 → sheet 40 → replay 50 → toast 60

### 3.5 动效 token（丝滑统一）

| Token | 值 |
|---|---|
| `--dur` | 0.2s（微交互） |
| `--dur-slow` | 0.3s（页面/卡片过渡） |
| `--ease` | `cubic-bezier(0.4,0,0.2,1)` |
| `--ease-spring` | `cubic-bezier(0.34,1.56,0.64,1)`（弹性） |

**规则**：只用 transform/opacity 动画（不动画 width/height）；reduced-motion 时 `--dur` 归零。

## 四、页面 UX 设计（5 Tab）

### 4.1 策略页（自然语言 → 量化配置）

**流程**：选择「选股/交易」→ 自然语言描述 → AI 多轮追问 → 审查量化配置 → 保存。

**UX 要点**：
- 对话界面：微信式气泡，AI 追问用「当前量化理解 + 确认问题」结构化展示
- 审查页：**字段全部中文化**（`pnl_pct`→「浮盈亏%」），条件编辑器用「一句话式」（`当 [浮盈亏%] [≤] [-5]`），不用英文 token 堆砌
- 交易策略有「入场条件（可选）」区块，选股策略有「股票池」区块
- 保存按钮为唯一主 CTA，其余为次级

### 4.2 选股页

**流程**：选策略 → 选股票池（沪深300/创业板/全市场等）→ 选日期区间 → 开始选股 → 进度 → 结果（勾选带去回测）。

**UX 要点**：
- 股票池下拉明确标注成分股数（「创业板指（100只成分股）」vs「创业板（全部股票）」），避免用户误解
- 选股中：进度条 + 全局顶部指示器（切页后后台继续，返回恢复进度）
- 结果：命中数 + 信号依据 chip + 信号后 5/20 日涨跌对比大盘

### 4.3 回测页

**流程**：选交易策略 → 回测池（选股勾选 或 自选股添加）→ 日期区间 → 运行 → 报告。

**UX 要点**：
- 回测池两种来源清晰：选股勾选（有信号日）/ 自选股添加（用交易策略 entry 入场）
- 报告：每票独立收益展示（不聚合平均），顶部 K线 + 买卖点标注，交易明细可展开
- 买卖点用「红▲买 / 绿▼卖」+ 触发原因（exit_reason 中文化）

### 4.4 行情页（K线 + 自选）

**流程**：顶部 segment 切换「K线 / 自选」。

**K线 UX 要点**：
- **十字光标 scrub**：按住左右滑动，十字光标跟随、浮层实时显示该日开高低收；松手停在最后悬浮 K线；滑到边缘不平移（时间轴不动）
- **上下滑动滚页面**：canvas 支持垂直滚动（`touch-action: pan-y`），手机无滚轮也能滚
- **左右按钮翻历史**：`‹更早 / 更新›`，短按翻半屏、长按连续翻
- K线颜色：**红涨绿跌**，阳线空心、阴线实心（不用颜色单独传达语义）

**自选 UX 要点**：
- 分组 tab（横向滚动）+ 搜索添加 + 重命名/删除（等宽按钮）
- 点击自选股 → 切回 K线模式

### 4.5 设置页

- 数据源 Key、LLM Key、默认股票池，表单分组清晰，Key 保存时清洗非法字符

## 五、交互规范

### 5.1 导航
- 底部 5 Tab（≤5 符合规范）：策略 / 选股 / 回测 / 行情 / 设置
- 图标 SVG（非 emoji），带文字标签，当前项高亮

### 5.2 触控与反馈
- 触控目标 ≥44px
- 按钮 press：`scale(0.98)` + 透明度（80-150ms 内反馈）
- 可点击卡片：桌面 hover 抬升、移动 press 缩放

### 5.3 状态反馈
- 加载：spinner / skeleton（避免长时间空白）
- 空态：引导文案 + 动作按钮（如「还没有策略，点此创建」）
- 错误：toast + 就近错误提示（含恢复路径）
- 后台任务：全局顶部指示器（切页不丢）

### 5.4 无障碍
- 对比度 ≥4.5:1
- 图标按钮有 aria-label / title
- 表单有 label（非 placeholder-only）
- reduced-motion 支持
- 颜色不是唯一信息载体（K线靠空心/实心，涨跌靠 ± 号 + 颜色）

## 六、响应式策略

| 断点 | 内容宽度 | 布局 |
|---|---|---|
| <768px（手机） | 全宽 | 单列，底部 5 Tab |
| ≥768px（平板） | 720px 居中 | 单列，可放宽 |
| ≥1024px（桌面） | 900px 居中 | 单列（内容型 App 不强制多列，保持一致性） |

**规则**：用 `--content-max` 变量分档（已实现），不写死 520px；桌面端内容居中、留白充足，不做「手机式窄条」。

## 八、交付前检查清单（pro-rules）

- [ ] 无 emoji 作图标（用 SVG）
- [ ] 图标来自统一家族、笔画一致
- [ ] 触控目标 ≥44px，无内容藏在安全区下
- [ ] 按压状态不位移（用 transform，不用 width/height）
- [ ] 主文本对比度 ≥4.5:1（浅色+深色各自验证）
- [ ] 375px 小屏 + 横屏不破版
- [ ] reduced-motion 生效
- [ ] 颜色不单独传达语义（K线空心/实心 + ± 号）
